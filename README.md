This repository contains the frontend and backend for a portfolio project that is intended to showcase my proficiency in JavaScript programming, as well as my ability to design User Interfaces (UI), create Application Programming Interfaces (APIs), and manage data flows between the database, backend and frontend of an application. 

The frontend is deployed on Netlify and can be viewed here:
[https://fullstackportfolios.netlify.app/](https://fullstackportfolios.netlify.app/)

[Render](https://render.com/) is used to host the backend of the project, and a [Supabase](https://supabase.com/) Postgres database is used to store user data. Given that this is a demonstration, sensitive data should not be used to test the sign-up and login functionality. E-Mail addresses will also not be verified, so it is best to use a non-existent address to test the sign-up.
